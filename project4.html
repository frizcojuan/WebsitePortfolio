UI/UX Design of a Mobile Programming Learning App

Mobile Programming Practicum (Java Android) Project • Universitas Prima Indonesia

Figma Android Studio Java UI/UX Design Mobile Prototyping

Overview

This project focuses on the User Interface (UI) and User Experience (UX) Design of an educational mobile application built for learning mobile programming. Developed as part of the Java Android-based Mobile Programming Practicum, the application aims to provide students and beginners with an intuitive, interactive, and structured platform to study programming concepts.

Key Features & Design Highlights

  • User-Centered Mobile Interface: Designed intuitive navigation, clear visual hierarchy, and accessible controls tailored for mobile screens using Figma.
  • Interactive Learning Modules: Structured lesson paths, code snippet previews, and progress tracking indicators to enhance learning engagement.
  • High-Fidelity Prototyping: Created interactive prototypes in Figma to map user flows before implementing layout XML and Java logic in Android Studio.
  • Responsive Layout System: Optimized interface elements for various Android mobile screen sizes and orientations.

Project Impact

This project combined human-centered UI/UX design principles with practical Android development tools, creating a seamless bridge between visual design conceptualization and front-end mobile execution.

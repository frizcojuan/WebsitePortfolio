Quiz Management System

Object-Oriented Programming Practicum Project • Universitas Prima Indonesia

Java NetBeans MySQL Desktop Application OOP Concepts

Overview

The Quiz Management System is a Java-based desktop application developed using NetBeans and MySQL as the final project for the Object-Oriented Programming Practicum. The system provides a structured digital environment for conducting automated quizzes and exams while managing student performance records.

Key Features

  • Student Quiz Portal: Provides students with an intuitive interface to take scheduled quizzes, select answers, and view instant grading results.
  • Admin & Instructor Panel: Allows educators to manage question banks, set passing scores, and monitor overall class performance.
  • Automated Grading & Analytics: Calculates scores automatically upon quiz completion and stores detailed attempt history.
  • Database Integration: Connects to a MySQL relational database to handle secure user authentication, question storage, and score records.

Project Impact

This project effectively applied core Object-Oriented Programming (OOP) principles such as encapsulation, inheritance, and polymorphism in Java to build a maintainable desktop software solution.

E-Commerce Website

E-Commerce Course Project • Universitas Prima Indonesia

HTML/CSS JavaScript PHP MySQL E-Commerce Platform

Overview

The E-Commerce Website was developed as the final project for the E-Commerce course. The platform implements core electronic commerce concepts through a web-based environment designed to support seamless product exploration and online transaction workflows.

Key Features

  • Product Catalog & Filtering: Displays available products with detailed descriptions, pricing, and category filters for easy navigation.
  • Interactive Shopping Cart: Allows users to add, update, and manage selected items prior to checkout.
  • Transaction & Order Flow: Streamlines the purchase process from cart review to order confirmation and transaction summary.
  • Database Management: Backed by MySQL to handle dynamic product inventories, user details, and transaction logs.

Project Impact

This project demonstrated practical skills in combining front-end interfaces with back-end database operations, establishing a full user flow for web-based retail applications.
